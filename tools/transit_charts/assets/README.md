# Przykładowe wykresy

Rendery użyte w [README](../README.md) oraz pełny zestaw z jednego dnia.

## `examples/` — po jednym wykresie każdego typu

Ilustracje wstawione w katalogu wykresów w README. Łódź 2026-07-21, okno nagrywania
10:07–21:59 (bez porannego szczytu), linie 11 / 10B / 69A — **poza H31 i I37**, które
z tego samego powodu co D15 potrzebują pełnej doby i pochodzą z 2026-07-23.

## `full-day-example/` — pełna doba, jeden folder na linię

Łódź **2026-07-23, 06:00–21:59** — nagranie obejmujące oba szczyty. Każdy folder ma własny
`README.md`, w którym wszystkie wykresy tej linii są widoczne od razu, bez klikania w pliki.

| linia | folder |
|---|---|
| 10A | [`full-day-example/10A`](full-day-example/10A/README.md) |
| 11 | [`full-day-example/11`](full-day-example/11/README.md) |
| 14 | [`full-day-example/14`](full-day-example/14/README.md) |
| 15 | [`full-day-example/15`](full-day-example/15/README.md) |
| 52 | [`full-day-example/52`](full-day-example/52/README.md) |
| 55 | [`full-day-example/55`](full-day-example/55/README.md) — tylko 55A; 55B i 55C nie mają tego dnia ani jednej obserwacji |
| 69 | [`full-day-example/69`](full-day-example/69/README.md) — 69A i 69B osobno, bo w szczycie popołudniowym kursy przechodzą z 69A na 69B |

Po dziesięć wykresów na linię: A2, C9, C10, C11, B5, B6, B7, D14, D17 z 2026-07-23 plus D15,
który wymaga kilku dni i liczony jest z trzech pełnych dni roboczych (2026-07-20, -23 i -24).
